# ML-модели

## Комплект Android-приложения

Источник актуального комплекта: [ModelCatalog.kt](../src/android/ml/src/main/java/com/team404bnf/ml/ModelCatalog.kt). Пакет `offline-ru-v1` включает все три компонента; отдельной установки только ASR для полного сценария недостаточно.

| Компонент | Назначение в коде | Артефакты |
| --- | --- | --- |
| GigaAM v3 E2E RNNT, FP32 | Распознавание русской речи | encoder, decoder, joint ONNX; config, YAML, словарь |
| Silero VAD v6.2.1 | Выделение участков речи | `silero_vad_v6.2.1.onnx` |
| WeSpeaker CAM++ | Голосовые представления для диаризации и кластеризации | `voxceleb_CAM++.onnx` |

GigaAM привязан к revision `322c3b29492673eb7d0b434bfa9dfb8653e34d02` репозитория `istupakov/gigaam-v3-onnx`. Источники Silero и WeSpeaker — Hugging Face; точные HTTPS URL, ожидаемые SHA-256 ONNX и допустимые размеры заданы в каталоге. Для небольших конфигурационных файлов GigaAM отдельные SHA-256 не заданы: используются закреплённая revision и проверки размера. Это ограничение проверки не следует описывать как хеширование всех файлов.

[ModelManager](../src/android/ml/src/main/java/com/team404bnf/ml/ModelManager.kt) проверяет установленный комплект и загруженные веса, поддерживает временные `.part` и возобновление загрузки при подходящем HTTP Range. Сетевой доступ используется для подтверждённой пользователем установки; аудио обрабатывается локально. Веса хранятся в приватной директории приложения и не входят в Git/APK. Оценка размера загрузки в каталоге — 970 000 000 байт, это не замер RAM и не гарантированный размер установки.

Используется ONNX Runtime Android 1.31.1. Проверка готовности выполняется при запросе расшифровки и перед ML. Повреждённый комплект требует восстановления через экран моделей; удаление комплекта не удаляет записи, снимки и правки.

Лицензионные условия моделей следует сверять с их источниками перед распространением весов: лицензия исходного приложения не заменяет лицензии моделей. В [бенчмарке](ML_BENCHMARKS.md) приведены измерения Windows CPU; измерения WER, DER и скорости на целевых Android-устройствах не предоставлены.

## Модели, испытанные на аудио

В таблице — кандидаты с сохранёнными прогонами на [тестовых WAV](../artifacts/ml-benchmarks/README.md). В APK доступны компоненты комплекта `offline-ru-v1` из раздела выше.

| Задача | Модель или связка | Режимы испытаний | Результат выбора |
| --- | --- | --- | --- |
| ASR | Faster-Whisper Tiny | CPU, без общей нарезки | Быстрее остальных в этом сравнении, WER 38,0% |
| ASR | Faster-Whisper Base | CPU, без общей нарезки | WER 28,8% |
| ASR | Faster-Whisper Small | CPU, два режима: с общей нарезкой и без неё | WER 19,1% и 18,5% соответственно |
| ASR | GigaAM v3 E2E RNNT (`gigaam-v3-e2e-rnnt`, ONNX через `onnx-asr`) | CPU, короткие чанки; оба набора | Выбрана для приложения: WER 8,7% и 8,0% |
| Диаризация | Pyannote Community-1 | Auto на обоих наборах; Oracle на основном | Контрольный вариант, медленнее на Windows CPU |
| Диаризация | Sherpa-ONNX: сегментация `model.onnx`, эмбеддер `3dspeaker_speech_eres2net_base_sv_zh-cn_3dspeaker_16k.onnx` | Auto 0,5 и 0,8, Oracle; `window_shift_ratio=0.1`, без INT8 | Порог 0,8 оставлен как резерв; на основном наборе DER 13,8% |
| Диаризация | Silero VAD v6.2.1 + WeSpeaker CAM++ (`voxceleb_CAM++.onnx`) | VAD 0,5; окно 2 с, шаг 0,8 с; cosine distance, average linkage; Auto 0,35/0,55/0,65, Fixed 2 и перебор порогов по эмбеддингам | Выбрана связка с порогом 0,55: минимальный общий cpWER и RTF диаризации в обоих наборах |

У связки Silero + CAM++ SHA-256 весов из отчёта об эмбеддингах совпадают с пинами Android-каталога. Для GigaAM отчёт идентифицирует семейство и вариант модели; происхождение текущего Android-артефакта зафиксировано отдельно в каталоге. Совпадение весов не подтверждает эквивалентность вычислений Python и Kotlin.

**Рассматривались без прогона:** Picovoice Falcon (в исходном отчёте указаны AccessKey и условия лицензирования), Silero + SpeechBrain ECAPA-TDNN и WeSpeaker ECAPA-TDNN. Показатели качества и скорости для этих вариантов не заявляются. Исходные ссылки, условия и все диагностические варианты сохранены в [отчёте о выборе](../artifacts/ml-benchmarks/model-selection-report.docx) и [таблице сравнения](../artifacts/ml-benchmarks/model-comparison.xlsx).
