# 404BNF

Android-приложение для записи разговоров, локального распознавания русской речи и разделения реплик по говорящим. Интерфейс — Dark Archive.

Запись или импорт → проверка моделей → очередь расшифровки → фоновая обработка → редактируемая расшифровка. Если моделей нет, аудио сохраняется; после подтверждённой пользователем загрузки ожидающие задачи продолжаются автоматически.

## Качество моделей на тестовом аудио

Испытали модели на **7 записях Veche-Bench**: чистый диалог, перебивания, шум и совещания с 3–6 участниками. Замеры сделаны на Windows CPU (Intel Core i3-7020U, 8 ГБ RAM).

| Набор | GigaAM: WER / CER | Silero + WeSpeaker CAM++: DER | GigaAM + CAM++: cpWER |
| --- | ---: | ---: | ---: |
| Основной, 4 записи | **8,7% / 5,8%** | 15,4% | **17,3%** |
| Дополнительный, 3 записи | **8,0% / 6,8%** | 14,4% | **26,1%** |

GigaAM показала наименьший WER среди испытанных вариантов ASR. Silero + CAM++ дала наименьший общий cpWER и самый низкий RTF диаризации на обоих наборах (0,16 и 0,09), при этом точно определила число говорящих в 2 из 7 записей. Это результаты Windows, без оценки производительности Android APK.

## Возможности

- Запись с паузой, импорт аудио и фоновая очередь расшифровки.
- Группировка реплик, редактирование отдельного фрагмента, смена говорящего, удаление и восстановление, сброс правок к оригиналу.
- Экспорт TXT и JSON с выбором оригинала или исправленной версии при различиях; экспорт WAV для WAV-источника и MP3.
- Обработка и хранение аудио на устройстве. Интернет нужен для загрузки моделей; веса в APK не включены.

Для сборки откройте `src/android/` в Android Studio или следуйте [инструкции](docs/INSTALLATION.md). [Проверки сборки и кода](docs/BUILD_CHECKS.md) фиксируют 140 unit-тестов `app` и 23 теста `ml` без ошибок, а также сборку и подпись debug APK.
