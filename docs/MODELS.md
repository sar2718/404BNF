# ML-модели

Источник актуального комплекта: [ModelCatalog.kt](../src/android/ml/src/main/java/com/team404bnf/ml/ModelCatalog.kt). Пакет `offline-ru-v1` включает все три компонента; отдельной установки только ASR для полного сценария недостаточно.

| Компонент | Назначение в коде | Артефакты |
| --- | --- | --- |
| GigaAM v3 E2E RNNT, FP32 | Распознавание русской речи | encoder, decoder, joint ONNX; config, YAML, словарь |
| Silero VAD v6.2.1 | Выделение участков речи | `silero_vad_v6.2.1.onnx` |
| WeSpeaker CAM++ | Голосовые представления для диаризации и кластеризации | `voxceleb_CAM++.onnx` |

GigaAM привязан к revision `322c3b29492673eb7d0b434bfa9dfb8653e34d02` репозитория `istupakov/gigaam-v3-onnx`. Источники Silero и WeSpeaker — Hugging Face; точные HTTPS URL, ожидаемые SHA-256 ONNX и допустимые размеры заданы в каталоге. Для небольших конфигурационных файлов GigaAM отдельные SHA-256 не заданы: используются закреплённая revision и проверки размера. Это ограничение проверки не следует описывать как хеширование всех файлов.

[ModelManager](../src/android/ml/src/main/java/com/team404bnf/ml/ModelManager.kt) проверяет установленный комплект и загруженные веса, поддерживает временные `.part` и возобновление загрузки при подходящем HTTP Range. Сетевой доступ используется для подтверждённой пользователем установки; аудио обрабатывается локально. Веса хранятся в приватной директории приложения и не входят в Git/APK. Оценка размера загрузки в каталоге — 970 000 000 байт, это не замер RAM и не гарантированный размер установки.

Используется ONNX Runtime Android 1.31.1. Проверка готовности выполняется при запросе расшифровки и перед ML. Повреждённый комплект требует восстановления через экран моделей; удаление комплекта не удаляет записи, снимки и правки.

Лицензионные условия моделей следует сверять с их источниками перед распространением весов: лицензия исходного приложения не заменяет лицензии моделей. Данная подготовка не включает юридическую проверку права распространения. Измерения WER, DER и скорости на целевых Android-устройствах не предоставлены; [ограничения](LIMITATIONS.md).
