# Состояние очистки репозитория

После согласования удалены шесть исторических документов (M1, M2, A14, A15, A16, A17), пять пустых `.gitignore` и избыточный `src/android/app/.gitignore`. Незакоммиченные пользовательские аудиты и UI-тест сохранены без изменения. Исходники приложения и Gradle-проекта не изменялись.

| Решение | Файлы / группа | Причина |
| --- | --- | --- |
| Оставить | Главный README, INSTALLATION, ARCHITECTURE, MODELS, LIMITATIONS, TEST_RESULTS | Единый пакет для экспертов |
| Оставить | `src/android/` со всеми исходниками, тестами, Gradle Wrapper JAR/properties, version catalog, daemon JVM properties, manifests, ресурсами и лицензиями шрифта | Воспроизводимость и происхождение зависимостей |
| Оставить | `src/ml-core/`, requirements/lock, schema и MODEL_SETUP | Отдельная Python-референсная реализация; не требуется для запуска APK |
| Объединить по смыслу | Старый `src/android/README.md` | Устаревшее утверждение об отсутствии ML заменено коротким входом в единую документацию |
| Удалено по согласованию | `docs/M1_ANDROID_ML_SETUP.md`, `M2_ANDROID_GIGAAM.md`, `A14_GIGAAM_SESSION_OPTIMIZATION.md`, `A16_UNLIMITED_AUDIO_STREAMING.md`, `A17_BACKGROUND_TRANSCRIPTION.md` | История этапов; актуальная реализация описана в финальной документации |
| Удалено по согласованию | `docs/A15_DIARIZATION_ACCURACY_AUDIT.md` | Исторические исследовательские заметки; их выводы не заявлены как измеренная точность APK |
| Не трогать без отдельного согласования | `docs/ANDROID_ARCHITECTURE_HANDOFF.md`, `ANDROID_ML_INTEGRATION_AUDIT.md`, `A13_ANDROID_ML_RUNTIME_AND_LIMITS_AUDIT.md` | Пользовательские незакоммиченные документы. A12/A13 содержат устаревшие ограничения и отсутствие управления моделями |
| Не трогать без согласования | Локальный `src/android/app/src/androidTest/java/com/team404bnf/app/ui/DarkArchiveUiTest.kt` | Незавершённый UI-тест, не запускался и не включён в доказательства тестирования |
| Исключить из Git | `build/` на всех уровнях, `.gradle/`, `.kotlin/`, IDE-кэши, `local.properties`, окружения Python, журналы, веса и личные аудиофайлы | Генерируемое или локальное; правила `.gitignore` дополнены |
| Исключить из обычного Git | `artifacts/apk/*.apk` | Пакет больше 100 МиБ; он уже загружен вложением Release v1.0.0-debug. Публикация черновика открывает доступ экспертам. Контрольная сумма и паспорт остаются обычными текстовыми файлами |
| Предложить к удалению локально | `.idea/`, `src/android/.idea/`, `.gradle/`, `.kotlin/`, `src/android/build/`, `app/build/`, `ml/build/` | Восстанавливаемые кэши/сборки. Сначала сохранить нужные результаты и APK; сейчас ничего не удалялось |
| Удалено | `config/.gitignore`, `docs/.gitignore`, `src/.gitignore`, `artifacts/demo/.gitignore`, `artifacts/test-results/.gitignore`, `src/android/app/.gitignore` | Первые пять были пустыми; правило `app/build` уже покрыто корневым `**/build/`. Проверка игнорирования до и после совпала |

Три README имеют разные роли: главный — презентация, Android — точка входа разработчика, Python — описание самостоятельного референсного ядра. Python README содержит исторические метрики и формулировки о будущей Android-интеграции: перед архивированием/редактированием требуется отдельное решение; эти утверждения не перенесены в финальные результаты.

Проверка tracked-файлов не выявила весов моделей, APK или каталогов сборки. Проверка секретов описана в TEST_RESULTS; она не заменяет аудит всей истории Git. История и индекс не переписывались.

Рабочие правила исключения сохранены в `.gitignore`, `src/android/.gitignore` и `src/ml-core/.gitignore`. Они защищают локальные настройки, кэши, сборки, веса и личные записи; сводить их в один файл без необходимости не требуется.
