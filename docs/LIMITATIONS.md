# Ограничения

- Предоставляется debug APK, а не production release. API 26 — минимальный уровень из манифеста; список проверенных устройств, минимум RAM и гарантии для каждого ABI отсутствуют.
- В Android используется FP32 GigaAM. Комплект требует загрузки и места для моделей, аудио и временного PCM; на длинных записях растут время, расход диска и нагрузка. Режим «Без ограничений» относится к пользовательскому лимиту размера импорта и не обещает неограниченные ресурсы.
- Кандидаты импорта: WAV, MP3, M4A, AAC, FLAC, OGG, OPUS, AMR, 3GP. Фактическое принятие зависит от дорожек, целостности и доступного декодера Android; наличие расширения недостаточно. Видео, в том числе контейнер с видеодорожкой, отклоняется. На устройствах все сочетания контейнеров/кодеков в этой подготовке не проверены.
- WAV-экспорт копирует WAV-источник, не является универсальным конвертером произвольного аудио в WAV. MP3 имеет отдельный декодер/кодировщик.
- Качество распознавания, число говорящих, наложенная речь и точность времён требуют оценки на размеченных записях. Unit-тесты не доказывают качество ML. Исторические Python-метрики не являются измерениями текущего Android APK.
- Фоновая обработка зависит от ограничений ОС и Foreground Service. После завершения процесса активные стадии отмечаются прерванными; автоматический бесконечный retry не реализован. Ожидание моделей сохраняется отдельно как состояние задачи A17.
- Сохранение приватное, backup отключён. Удаление приложения/его данных удаляет локальный архив; экспортируйте нужные материалы заранее.

## Материалы для сдачи

Видеодемонстрация не предоставлена. Новые пустые директории и фиктивные видео/ссылки не созданы; существующий `artifacts/demo/.gitignore` — историческая заготовка. После получения реального видео его следует разместить в `artifacts/demo/` и добавить прямую ссылку в главный README.

Скриншоты текущего приложения также не предоставлены в репозитории. Директория `artifacts/screenshots/` появится после получения реальных изображений; иконка приложения не считается скриншотом.

Debug APK подготовлен локально; его размер превышает обычный файловый лимит GitHub. До удалённой сдачи требуется разместить его как Release asset либо настроить Git LFS и опубликовать реальную ссылку — см. [паспорт APK](../artifacts/apk/README.md). Загрузка в сервисы и публикация в ходе подготовки не выполнялись.
