В ZIP сохранены исходные имена и содержимое результатов. Название папки `results_realData` историческое: в ней прогоны на дополнительном наборе сценарных совещаний. Сохранённые в логах и разметке пути относятся к исходной среде прогона; в репозитории файлы следует находить по ID записи. Исходный `tests_404bnf.zip` не дублируется целиком: его SHA-256 — `9f3a5a23a5af15d234fd474b72958778ceeef85caed51ff1ef1a07e9ff326eff`.

## Проверка материалов и пересчёт ASR

Из корня репозитория:

```bash
(cd artifacts/ml-benchmarks && sha256sum -c SHA256SUMS)
python3 artifacts/ml-benchmarks/score_asr.py
```

[Скрипт пересчёта](score_asr.py) печатает CSV с WER/CER и RTF для каждой записи и `micro` по набору. WER считает расстояние Левенштейна по токенам `\w+` после перевода в нижний регистр и замены `ё` на `е`; CER считает его по тем же токенам, соединённым без пробелов. RTF использует сохранённое время инференса и длительность WAV. Скрипт проверяет сохранённые гипотезы по эталонам и не загружает модели.

Для нового инференса выбранной связкой используйте [Python ML-ядро](../../src/ml-core/README.md) и передайте WAV из соответствующей папки через `--audio`. Веса и исторические скрипты прогона всех сравниваемых моделей в приложенный пакет не входят.
