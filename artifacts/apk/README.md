## Публикация до сдачи

Файл больше 100 МиБ: обычный GitHub push его не примет — [правила GitHub](https://docs.github.com/en/repositories/working-with-files/managing-large-files/about-large-files-on-github). Локальная копия явно исключена через `.gitignore`; текстовые паспорт и сумма предназначены для Git.

Для удалённой сдачи загрузите именно этот APK и SHA256SUMS как реальные Release assets, затем замените ссылку на APK в этом документе реальной ссылкой скачивания. Альтернатива — согласованная настройка Git LFS. Сейчас публикации нет; при обычном клонировании локальная копия не появится. Для передачи папкой/архивом включите её вручную либо соберите APK по инструкции. Вымышленная ссылка на Release не создавалась.
