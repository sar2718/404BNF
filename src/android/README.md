# 404BNF

**404BNF** — мобильное Android-приложение для записи аудио, воспроизведения и удобной интерактивной работы с расшифровками диалогов (расшифровка речи, разделение по спикерам и редактирование).

---

## 🚀 Назначение приложения

Приложение предназначено для записи аудиозаписей (интервью, лекций, совещаний), загрузки и визуального прослушивания структурированных расшифровок с разделением участников и временными метками, а также редактирования реплик и экспорта результатов.

---

## 🛠 Используемые технологии

- **Язык разработки:** Kotlin (Modern Android Development)
- **Пользовательский интерфейс:** Jetpack Compose, Material 3
- **Архитектура:** Clean Architecture / MVVM (ViewModel, StateFlow, Coroutines)
- **База данных:** Room (SQLite)
- **Аудиоплеер:** Jetpack Media3 (ExoPlayer)
- **Запись звука:** Android `AudioRecord` + `ForegroundService` (с уведомлением и фоновой записью)
- **Сериализация:** Gson / JSON Parser
- **Тестирование:** JUnit 4

---

## ✨ Реализованный функционал

- 🎙 **Запись аудио:** Фоновая запись звука с микрофона через `Foreground Service` с поддержкой паузы, возобновления и управления из сервиса.
- 💬 **Диалоговые расшифровки:** Загрузка, валидация и парсинг JSON-результатов расшифровки речи (сегменты, таймкоды, спикеры).
- 🧩 **Автоматическая группировка:** Интеллектуальное визуальное объединение последовательных реплик одного говорящего (пауза ≤ 1.5 сек).
- 🔄 **Синхронизация воспроизведения:** Интерактивная подсветка текущей звучащей реплики, автоскролл и реакция на ручные жесты пользователя.
- ✏️ **Редактирование:** Смена говорящего (для отдельного фрагмента или всей группы), изменение текста, переименование участников, скрытие реплик с возможностью их восстановления.
- 💾 **Экспорт данных:** Локальный экспорт отредактированной расшифровки в текстовый файл `.txt` и аудиозаписи в файл `.wav` (без перекодирования).
- 🔒 **Приватность:** Полностью локальная обработка и хранение данных на устройстве без сторонних серверов.

---

## 🤖 Статус ML-интеграции

На данный момент клиентское приложение реализует готовую модель данных, валидацию и UI-слой для отображения диалоговой расшифровки на основе структурированного JSON-формата.

Прямой запуск тяжёлых ML-моделей речевой аналитики (ASR и диаризации спикеров) на самом Android-устройстве находится на этапе проектирования и тестирования нативных библиотек. Архитектура приложения изолирована от тяжёлых вычислений, а UI работает с хранилищем результатов асинхронно.

## 💻 Сборка и запуск

### Открытие в Android Studio

1. Запустите Android Studio (Ladybug или более новую версию).
2. Выберите **Open** и укажите директорию проекта `404BNF`.
3. Дождитесь завершения синхонизации Gradle (**Gradle Sync**).

### Сборка Debug APK из терминала

Для сборки отладочной версии приложения выполните команду:

```bash
./gradlew :app:assembleDebug
```

Готовый APK-файл будет находиться по пути:
`app/build/outputs/apk/debug/app-debug.apk`

### Запуск Unit-тестов

Для запуска автоматических модульных тестов выполните:

```bash
./gradlew :app:testDebugUnitTest
```
