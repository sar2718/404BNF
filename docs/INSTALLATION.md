# Установка и использование

## APK

Скачайте [404BNF-1.0-debug.apk](https://github.com/sar2718/404BNF/releases/download/v1.0.0-debug/404BNF-1.0-debug.apk) и [SHA256SUMS](https://github.com/sar2718/404BNF/releases/download/v1.0.0-debug/SHA256SUMS) из [опубликованного релиза `v1.0.0-debug`](https://github.com/sar2718/404BNF/releases/tag/v1.0.0-debug). Проверьте сумму командой `sha256sum -c SHA256SUMS` из папки скачивания. [Паспорт сборки](../artifacts/apk/README.md). Это демонстрационная отладочная сборка, не production release. Установку из выбранного источника необходимо разрешить в настройках Android. Минимум по манифесту — Android 8.0 / API 26; наличие подходящей версии ОС не подтверждает достаточную производительность устройства.

APK содержит нативные библиотеки `arm64-v8a`, `armeabi-v7a`, `x86`, `x86_64`. Фактическая работа ML на каждом ABI этим не подтверждена. При обновлении требуется совместимая подпись установленного приложения; удаление приложения ради переустановки удаляет его локальные данные.

## Сценарий использования

1. Примите пользовательское соглашение. В разделе моделей можно явно подтвердить загрузку комплекта; без моделей библиотека и сохранение аудио доступны.
2. Разрешите микрофон для записи и уведомления для отображения фоновых операций, когда ОС запрашивает разрешения.
3. Нажмите «Записать», затем завершите запись, либо выберите «Импорт» и аудиофайл. После сохранения расшифровка запрашивается автоматически.
4. При сообщении «Для расшифровки необходимо скачать модель распознавания» нажмите «Скачать модель». Откроется существующий экран моделей; загрузка начнётся после нажатия кнопки загрузки на нём. После успешной проверки комплекта ожидающие задачи продолжатся автоматически. Ожидание можно отменить.
5. Состояние записи видно в библиотеке. В расшифровке удерживайте сообщение для действий; в группе выберите отдельный фрагмент для редактирования. В редакторе доступно прослушивание границ фрагмента.
6. Кнопка «Экспорт» предлагает доступные форматы. Для TXT/JSON при различиях выбирается оригинальная или исправленная версия. Экспорт не запускает ML.

В настройках максимального размера по умолчанию выбрано «Без ограничений». Доступны готовые значения и ручной ввод целого числа МБ; явно сохранённый выбор сохраняется между запусками.

## Сборка из исходников

Исходная директория — `src/android/`. Требуются Android SDK Platform 37, доступ к репозиториям зависимостей и JVM для Gradle. В репозитории заданы Gradle Wrapper 9.6.0, Android Gradle Plugin 9.5.1, Kotlin 2.2.10 и daemon toolchain Java 25. Wrapper проверяет SHA-256 дистрибутива. Уровень Java исходников — 11; он не является требованием к JVM Gradle.

Укажите SDK локально через `ANDROID_HOME` либо неотслеживаемый `local.properties` с `sdk.dir`. Не переносите локальные абсолютные пути в Git. Gradle daemon toolchain может потребовать отдельной загрузки Java 25.

Из корня репозитория:

```bash
cd src/android
./gradlew :app:assembleDebug
```

В среде подготовки использовалось `JAVA_HOME=/opt/android-studio/jbr ./gradlew :app:assembleDebug`; на другой машине задайте собственный путь к JDK. Результат: `src/android/app/build/outputs/apk/debug/app-debug.apk` относительно корня репозитория.

Модели для компиляции и unit-тестов скачивать не требуется. Для запуска ML комплект устанавливается через приложение; см. [модели](MODELS.md) и [результаты тестов](TEST_RESULTS.md).
